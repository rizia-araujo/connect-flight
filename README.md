# ConnectFlight

Página inicial de agência de viagens feita em React + Vite, baseada em protótipo do Figma.
Atividade avaliativa — Programação para WEB II (UNITINS).
4º Período - TADS

## Como rodar
```bash
npm install
npm run dev
```
Abra http://localhost:5173

## Páginas
- `/` Início
- `/destinos` Destinos
- `/ofertas` Ofertas
- `/contato` Contato

## Estrutura
```
src/
  components/  peças reutilizáveis (Layout, Hero, Footer, Cards, Form...)
  pages/       telas (Home, Destinos, Ofertas, Contato)
  data/        dados usados pelas telas
```
